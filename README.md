# 🌀 Woo-chi Hacker Toolkit (전우치 해커 툴킷)

조선의 도사 '전우치'의 도술을 현대적인 파이썬 기술로 재해석한 프로젝트입니다.

## 🛠 도술 구현 목록 (Tech Stack)

### 1. 분신술 (Bunsin-sul)
* **현대적 해석**: 시스템 자원을 극대화하는 **Multi-threading (병렬 처리)**.
* **기술 설명**: 하나의 프로세스에서 여러 개의 쓰레드를 생성하여, 전우치가 여러 명으로 분신하여 동시에 적을 교란하듯 데이터를 병렬로 처리합니다.
* **파일명**: `bunsin.py`

### 2. 은신술 (Hiding-sul)
* **현대적 해석**: 정보 보안의 핵심인 **Base64 Encoding & Data Hiding**.
* **기술 설명**: 족자 속으로 사라지는 전우치처럼, 텍스트 데이터를 Base64 방식으로 인코딩하여 사람이 바로 읽기 어려운 형태로 변환합니다.
* **파일명**: `hiding.py`

### 3. 천지조화 (Weather-Magic)
* **현대적 해석**: 외부 환경 데이터를 제어하는 **API Simulation**.
* **기술 설명**: 주문을 외워 날씨를 바꾸듯, 외부 시스템(API)과 통신하여 환경 변수를 읽어오고 시스템의 동작을 결정하는 로직을 구현했습니다.
* **파일명**: `weather.py`

---

## 🚀 실행 방법 (Usage)

각 도술은 파이썬 3 환경에서 독립적으로 실행 가능합니다.

```bash
python3 bunsin.py
python3 hiding.py
python3 weather.py

---

## 📊 실행 결과 (Execution Result)

전우치의 대표 도술인 **분신술**을 현대 프로그래밍 기술인 **멀티스레딩(Multi-threading)***으로*재해석하여 성능을 비교하였다.

### 실험 조건

* 작업 수 : 10개
* 작업당 수행 시간 : 1초

### 실행 결과

| 처리 방식                         | 실행 시간  |
| ----------------------------- | ------ |
| 순차 처리 (Sequential Processing) | 10.04초 |
| 멀티스레딩 (Multi-threading)       | 1.01초  |

### 결과 해석

동일한 작업 10개를 수행한 결과, 멀티스레딩을 적용했을 때 실행 시간이 약 **90% 단축**되었다.

이를 통해 전우치의 분신술이 여러 작업을 동시에 수행하는 개념과 유사하며, 현대 컴퓨터 과학에서는 이를 멀티스레딩 기술로 구현할 수 있음을 확인하였다.
